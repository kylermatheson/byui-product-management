# Student project instructions

This is a private BYU-Idaho Product Management student repo for Winter 2027 Second Block. Codex is the primary tool; Claude is a supported alternative. Both use the procedures in `course-prompts/`.

Ask one question at a time during setup, planning, reflection, and tutoring. Use the student's words. Never invent a role, project, plan goal, interview result, hours worked, or reflection answer. Mark unknown evidence as unknown. Read only projects and evidence the student authorizes. Keep secrets, raw session transcripts, private company code, identifiable interview notes, and recordings out of the course report and repo.

Inspect existing files before making changes. Preserve completed work and unrelated edits. Explain commands before running them. Never ask for a password or token. The student completes authentication in the provider's sign-in flow. Push only to the student's confirmed repository, after the student reviews the staged files and authorizes submission. Staff usernames and exact deadlines are blank until supplied; never guess them or execute a command containing placeholders.

Sprints 1–5 last one week each. Sprint 6 spans Weeks 6–7. The course runs February 22–April 8, 2027. Use the current published Assessments page for requirements and grading; templates are starting points, not finished work.
