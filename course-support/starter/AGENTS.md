# Student project instructions

This is a private BYU-Idaho Product Management student repo for Winter 2027 Second Block. Codex is the primary tool; Claude is a supported alternative. Both use the procedures in `course-prompts/`.

Ask one question at a time during setup, planning, reflection, and tutoring. Use the student's words. Never invent a role, project, plan goal, interview result, hours worked, or reflection answer. Mark unknown evidence as unknown. Read only projects and evidence the student authorizes. Keep secrets, raw session transcripts, private company code, identifiable interview notes, and recordings out of the course report and repo.

Inspect existing files before making changes. Preserve completed work and unrelated edits. Explain commands before running them. Never ask for a password or token. The student completes authentication in the provider's sign-in flow. Push only to the student's confirmed repository, after the student reviews the staged files and authorizes submission. Staff usernames remain blank until supplied; read `course-schedule.json` for dates and never guess missing meeting details or execute a command containing placeholders.

Sprints 1–6 each last one week in Weeks 1–6. Wrap-ups are due Saturdays, February 27 through April 3. Plans for Sprints 2–6 are due the preceding Saturday; Sprint 1 is written and submitted during the first class. All dated submissions close at 23:59 America/Boise. Week 7 has no new sprint. The course runs February 22–April 8, 2027. Use the current published Assessments page for requirements and grading; templates are starting points, not finished work.

Prepare using the short weekly essentials (20–30 minutes total per week); full chapters are optional references. Teach One Another means human peer explanation and respectful feedback in class. Ponder and Prove is application and reflection in the existing sprint work. Do not generate new graded posts, quizzes, essays, or extra reflection submissions. Exam scope is required essentials and explicitly taught class material, not all optional source topics.
