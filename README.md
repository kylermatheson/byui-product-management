# BYU–Idaho Product Management

This repository is a BYU–Idaho starting point for a Product Management course website. It is a Quarto book and includes reusable curriculum on product discovery, design, application architecture, AI systems, and launch and learning.

## Important attribution

The curriculum is adapted from the public [BYU Strategy Product Management course](https://github.com/byu-strategy/product-management), originally authored by Scott Murff. This repository is an independent course copy, not an official BYU–Idaho publication or endorsement. Review all content, citations, images, policies, and institutional notices before using it with students.

## Before publishing

Update the bracketed placeholders in `index.qmd`, `_quarto.yml`, and the schedule and assessment pages with your course number, term, instructor, meeting details, grading policy, due dates, LMS links, and BYU–Idaho-required notices.

## Build locally

Install [Quarto](https://quarto.org/), then run:

```bash
quarto preview
```

To render the static site:

```bash
quarto render
```

The rendered site is written to `_book/`.
